# SIPPA
## Sistem Informasi Peminjaman dan Pengembalian Alat

### Deskripsi
SIPPA adalah sistem informasi untuk mendata alat dan
mengelola transaksi peminjaman serta pengembalian alat.

### Tujuan
- Mempermudah pencatatan data alat.
- Membantu pemantauan stok alat.
- Mempermudah pencatatan peminjaman dan pengembalian.
- Menyimpan riwayat transaksi peminjaman.

### Teknologi
- PHP 8.3
- Git
- GitHub
- HTML dan CSS

### Status Proyek
Tahap awal pengembangan dan analisis kebutuhan untuk UTS
Rekayasa Perangkat Lunak.
